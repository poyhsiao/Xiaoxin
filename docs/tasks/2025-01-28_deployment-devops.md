## 1. 任務概述

## 2. Task List

### 2.1 完整 Docker Compose 配置

- [ ] **目標:** 完善 Docker 部署配置**

- **開發步驟:**
  1. 配置 PostgreSQL 容器
  2. 配置 Redis/Valkey 容器
  3. 配置 NestJS 後端容器
  4. 配置 Next.js 前端容器
  5. 配置 Nginx 反向代理
  6. 配置 volume 持久化

- **驗證方式:**
  - `docker-compose up` 成功啟動所有服務
  - 服務正常運作

- **期望輸出:**
  - `infra/docker/docker-compose.yml` - 完整配置

---

### 2.2 生產環境配置

- [ ] **目標:** 完成生產環境設定**

- **開發步驟:**
  1. 建立 `.env.production`
  2. 配置 HTTPS/SSL
  3. 配置 CORS
  4. 配置 rate limiting
  5. 配置日誌管理

- **驗證方式:**
  - 生產環境正常運作
  - 安全設定正確

- **期望輸出:**
  - 生產環境配置文檔

---

### 2.3 CI/CD Pipeline

- [ ] **目標:** 實現自動化部署流程**

- **開發步驟:**
  1. 建立 GitHub Actions workflow
  2. 配置自動化測試
  3. 配置自動化構建
  4. 配置自動化部署
  5. 配置 rollback 策略

- **驗證方式:**
  - PR 合併後自動部署
  - 測試失敗阻止部署

- **期望輸出:**
  - `.github/workflows/` - CI/CD 配置

---

### 2.4 監控與日誌

- [ ] **目標:** 建立監控和日誌系統**

- **開發步驟:**
  1. 配置日誌收集 (Loki/Prometheus)
  2. 配置 Grafana 儀表板
  3. 配置錯誤追蹤 (Sentry)
  4. 配置健康檢查端點

- **驗證方式:**
  - 可即時監控系統狀態
  - 錯誤可追蹤

- **期望輸出:**
  - 監控配置
